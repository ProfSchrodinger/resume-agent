Setup
Configure the agent to point to your local resume repo.
How to run
# 1. Install dependencies
pip install flask anthropic

# 2. Set environment variables
export RESUME_REPO_PATH=~/Documents/resume-latex
export ANTHROPIC_API_KEY=sk-ant-...

# 3. Run the app
python app.py
File structure expected
resume-latex/
├── src/
│ ├── experience.tex
│ ├── projects.tex
│ ├── projects-bank.tex  # all projects, never edited by agent
│ ├── skills.tex
│ ├── activities.tex
│ ├── heading.tex
│ └── education.tex
├── custom-commands.tex
├── resume.tex
└── tailored/            # agent saves here
Sync with Overleaf
# After editing in Overleaf: download source zip, copy to repo
cp ~/Downloads/resume-latex/*.tex ~/Documents/resume-latex/
cp ~/Downloads/resume-latex/src/*.tex ~/Documents/resume-latex/src/
git add . && git commit -m "sync from overleaf" && git push
